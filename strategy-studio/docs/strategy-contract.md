# Python 전략 계약: on_bar_v1

단일 UTF-8 `.py` 파일(최대 64KiB)에 동기 함수 `def on_bar(ctx):`를 하나 정의합니다.
코드는 현재 macOS 제한 작업 프로세스에서 실행됩니다. 외부 패키지·파일·네트워크 기반 전략은 지원하지 않습니다.
모듈 전역 변수는 한 실행 안에서 유지되지만 다른 실행과 공유되지 않습니다.

```python
def on_bar(ctx):
    if ctx["index"] == 0:
        return {"action": "buy", "reason": "첫 관측 후 매수"}
    return {"action": "hold"}
```

## 관측값

| 필드 | 내용 |
|---|---|
| `index` | 0부터 시작하는 현재 봉 번호 |
| `date` | 현재 봉의 `YYYY-MM-DD` |
| `bar` | 현재 봉의 `date`, `open`, `high`, `low`, `close` |
| `history` | 과거부터 현재 봉까지의 위 형식 목록. 미래 봉은 없음 |
| `portfolio` | 가상 `cash`, 정수 `shares`, 현재 종가 평가 `equity` |

현재 봉의 시가에서 직전 주문을 체결하고 현재 종가로 평가한 뒤 `on_bar`를 호출합니다.
관측값을 변경해도 호스트 잔고·시세는 변경되지 않습니다. 키·토큰·실계좌 잔고는 포함하지 않습니다.

## 반환값

`{"action": "buy" | "sell" | "hold", "quantity": 선택 정수, "reason": 선택 문자열}`

- 한 봉마다 한 객체만 반환합니다. 다른 필드·주문 목록·성과 수치는 허용하지 않습니다.
- `quantity`를 명시하면 1~10억의 정수여야 합니다. `hold`에는 수량을 넣지 않습니다.
- 수량 생략 시 다음 봉 시가에서 매수 가능한 전액 또는 보유 전량을 사용합니다. 가용 수량이 없으면 체결하지 않고 경고를 남깁니다.
- 명시 수량이 다음 봉 시가의 매수 가능 수량·보유 수량을 초과하면 실행 전체가 실패합니다. 현재 종가로 계산한 수량은 다음 시가 상승으로 실패할 수 있습니다.
- `reason`은 500자 이하입니다. 보고서에는 사용자 코드의 설명이며 독립 검증하지 않았다고 표시합니다.
- 판단은 다음 봉 시가에만 체결됩니다. 마지막 봉의 판단은 검사하되 다음 봉이 없어 체결하지 않습니다.

호스트가 잔고·체결·비용·수익률·낙폭을 계산합니다. 사용자 코드가 성과 값을 반환해 바꿀 수 없습니다.
`meritz_backtest_validate` 통과는 문법·진입점 확인일 뿐, 런타임 오류·자원 초과·보안·투자 성과 검증이 아닙니다.
