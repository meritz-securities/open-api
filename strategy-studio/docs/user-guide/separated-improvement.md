# 기간을 나눠 전략 개선·검증하기

한 기간의 결과만 보고 전략을 고르면 그 기간에만 잘 맞는 전략을 선택할 수 있습니다. 이 기능은 앞쪽 기간에서 개선안을 만들고, 뒤쪽 기간에서 원본과 선택된 개선안을 비교합니다. 수익을 보장하거나 과최적화가 없음을 인증하는 기능은 아닙니다. 실제 주문은 실행하지 않습니다.

## 사용할 수 있는 시세 범위

전체 시세는 4~5,000개 봉이어야 합니다. 일봉 자료라면 하루치가 한 개 봉입니다. 개선에 쓸 비율은 전체의 20~80%이며, 나눈 두 기간 모두 최소 2개 봉이 있어야 합니다. 자료가 부족하거나 범위를 넘으면 시세 기간을 바꾼 뒤 다시 시작하세요.

## 개선안은 어디서 오나요

Studio는 상용 AI 서비스에 연결하지 않으므로 Studio 안에서 AI가 개선안을 만들지는 않습니다. 개선안은 다음 경로로 들어옵니다.

- **MCP 경로**: 고객이 사용하는 AI 호스트에 이 앱을 `--mcp`로 등록하면, AI 호스트가 `meritz_ai_request_get`으로 개선 요청을 읽고 `meritz_ai_candidates_submit`으로 최대 3개 후보를 제출합니다. MCP 호스트는 `meritz_research_*` 계열 도구로 기간 분리 작업 자체를 만들고 진행할 수도 있습니다. 이 경로의 도구 호출 결과는 고객이 연결한 AI 서비스로 전송됩니다.
- 조건형(비주얼 빌더) 전략만 지원합니다. 직접 작성한 Python 전략은 이 기능의 지원 대상이 아닙니다.

## 사용 순서

1. 저장된 전략과 시세 자료를 선택하고 초기 자금·비용을 설정합니다.
2. **기간 나눠 개선·검증**을 선택합니다. 개선에 쓸 기간과 검증할 기간의 실제 날짜·자료 수를 확인합니다.
3. **개선 기간 계산**으로 앞쪽 기간에서 원본 전략을 실행합니다. 이 결과에 연결된 개선 요청으로 위 경로에서 최대 3개의 개선안을 제출받아 같은 기간에서 실행합니다.
4. 개선 후보를 제출하지 않은 경우에도 **원본으로 확정**을 선택할 수 있습니다. 원본 전략만 뒤쪽 기간에서 실행하며, AI 후보 비교 결과로 표현하지 않습니다. 개선 후보를 제출했다면 모든 후보 실행이 성공한 뒤에만 **후보 확정**을 사용할 수 있습니다. 앞쪽 기간의 수익률로 원본과 개선안 중 하나를 고르며, 수익률이 같으면 원본, 개선안 입력 순서를 우선합니다. 일부 후보만 성공했다면 후보 확정은 불가합니다.
5. 뒤쪽 기간에서 원본과 앞서 선택한 전략을 실행합니다. 원본으로 확정한 경우 원본만 실행합니다. 이 결과를 보고 선택된 전략을 바꾸지는 않습니다.
6. 원본보다 나빠진 결과도 함께 확인합니다. 저장된 작업을 다시 열어 실행 결과를 확인할 수 있습니다.

## 결과를 읽는 방법

| 항목 | 의미 |
|---|---|
| 개선에 사용한 기간 | 원본과 모든 개선안을 같은 조건으로 실행한 결과입니다. |
| 검증에 사용한 기간 | 미리 선택한 전략과 원본을 비교한 결과입니다. 선택되지 않은 개선안은 실행하지 않습니다. |
| 초기 자금 | 각 기간은 같은 초기 자금과 보유 수량 0에서 따로 시작합니다. 앞 기간의 잔고를 넘기지 않습니다. |
| 지표 준비 기간 | 각 기간에서 지표를 새로 계산합니다. 준비에 필요한 자료 때문에 실제 거래 가능한 기간이 줄어들 수 있습니다. |
| 실행 실패·중단 | 완료된 결과는 보존합니다. 일부 후보만 성공했다면 비교 대상을 확정하지 않습니다. 중단된 실행을 자동으로 다시 시작하지 않습니다. |

## 알아두실 점

- 이미 전체 기간을 실행했거나 직접 시세를 확인했다면, 뒤쪽 기간을 전혀 보지 않은 검증이라고 할 수 없습니다. 화면은 이 저장 시세의 이전 전체 기간 실행 횟수와 이전 기간 분리 횟수를 함께 표시하지만, 다른 저장본·외부 이용까지 포함한 전체 횟수는 아닙니다.
- 개선안을 작성하는 쪽(AI 호스트 또는 사용자)에는 앞쪽 기간의 계산 결과만 전달됩니다. 다만 사용자 요청과 전략 내용에 포함된 사전 지식까지 제거해 주지는 않습니다.
- 두 기간의 자산 곡선은 독립된 계정의 결과입니다. 하나의 연속된 투자 성과처럼 이어 붙이지 않습니다.
- 취소 요청은 즉시 강제 종료를 뜻하지 않습니다. 현재 처리 중인 계산이 취소 지점을 확인할 때까지 시간이 걸릴 수 있습니다. 확정·완료된 결과는 늦게 도착한 취소 요청으로 변경하지 않습니다.
- 뒤쪽 기간을 확인한 뒤 전략을 다시 수정하면, 그 자료는 이미 참고한 자료입니다. 새 작업으로 비교하더라도 이 사실은 달라지지 않습니다.
- 시세 자료의 누락, 비용 설정, 가상 체결 가정도 함께 확인하세요.
