# 베타 범위와 알려진 제한

이 문서는 베타(0.5.0b1)의 범위와, 그 안에서 **자동화 테스트와 코드로 확인한 것**을 적습니다.
표의 "확인" 은 자동화 검사 통과를 뜻하며, 정식 지원 선언이 아닙니다.

## 베타 범위

- 소스 코드로 실행하고(`uv run python platform_entry.py`) 기본 브라우저로 엽니다. 베타 기준은 브라우저 모드입니다. 자체 창(`--window`)은 소스의 선택 옵션으로 남아 있으며, 정식 제공 범위는 설치 파일(서명된 macOS 앱, Windows 설치본)과 함께 베타 이후입니다.
- 예제 전략·비주얼 빌더(DSL)·CSV 가져오기·리포트는 모든 OS 에서 같습니다. 직접 작성한 Python 전략은 macOS 격리 환경에서 실행하며,
  Windows 소스 실행에서는 비주얼 빌더 전략만 사용합니다([Windows 지원 범위](windows-v1-scope.md)).

| 기능 | 베타에서 확인한 것(자동화 검사 기준) |
|---|---|
| 예제 전략 35종·비주얼 빌더 | 35개 템플릿 DSL 테스트, 브라우저 자동화로 35개 전부 저장·검증·실행(`studio/tests/templates-all-runtime.spec.ts`) |
| 백테스트 결과·위험 진단 | 합성 데이터 원장 검산 26항목, 템플릿 불변식 5종 |
| 메리츠 국내·미국 일봉 조회 | 요청·저장 경로 자동화 테스트. 응답 기간·누락·수정주가 범위는 Studio 가 보장하지 않으며 품질 경고로 알립니다 |
| CSV 가져오기 | 형식·경계 자동화 테스트 |
| Python 전략 | macOS 격리 경로의 실행·자원 제한·가상 체결 테스트 |
| MCP 백테스트와 주문 경계 | `--mcp` 는 기존 Open API 도구와 전략 도구를 함께 등록하고 주문은 조회 전용 기본값에서 차단. 백테스트 결과는 주문으로 전달되지 않음 |
| JSON·CSV·HTML 내보내기 | 단위 검사, HTML 차트·월별 표·escape 경계 |
| 로컬 저장소와 초기화 | SQLite 자동화 테스트, 로컬 데이터 초기화 |
| AI | Studio 안에는 없음. AI 호스트가 MCP 도구를 사용 |
| 실주문 | 백테스트 경로에서 주문 API 호출 없음(테스트로 고정) |

## 지원하지 않는 것

- 배당 현금흐름, 액면분할·병합에 따른 수량 조정 등 기업행사 반영
- 다종목 포트폴리오, 환율 손익
- 거래소 달력 대조(기간 내 휴장일·누락 판정)

## 베타 기간의 약속

- 소스 코드로 제공합니다. 설치 파일·서명된 실행 파일은 베타 이후에 배포합니다.
- 기능·화면·저장 형식이 바뀔 수 있습니다. 저장한 전략·실행 결과는 다음 버전에서 열리지 않을 수 있으니 필요한 결과는 HTML·CSV 로 내보내 두십시오.
- 문제와 의견은 GitHub 이슈로 받습니다. 응답 기한을 약속하지 않습니다. 계좌·주문·앱키 문의는 개발자 포털 문의 채널을 이용해 주십시오.
- 실제 앱키를 쓰는 시세 조회는 조회 작업만 하며 주문·환전은 실행하지 않습니다.
