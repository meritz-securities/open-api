# 면책 및 이용 조건

이 저장소는 전략 백테스트 Studio와, 메리츠증권 Open API 를 **AI 에이전트가 호출하도록**
연결해 주는 MCP 서버를 담고 있습니다. 설치하거나 연결하시기 전에 반드시 읽어 주십시오.
아래 **전략 백테스트 Studio** 절은 Studio(자체 창·브라우저·CLI)에, 그 다음 절부터는 MCP 서버에 해당합니다.

## 전략 백테스트 Studio

- **베타 버전입니다.** Studio 는 소스 코드로 제공하는 베타이며 정식 서비스가 아닙니다. 기능·화면·저장 형식이 사전
  안내 없이 바뀔 수 있고, 저장한 전략·결과가 다음 버전에서 열리지 않을 수 있습니다. 베타 기간의 문의는 GitHub 이슈로만
  받으며 응답 기한을 약속하지 않습니다. 베타 범위는 [베타 범위와 알려진 제한](docs/customer-readiness.md)을 보십시오.
- **가상 체결이며 실주문이 없습니다.** 백테스트는 저장된 과거 시세에 규칙을 적용해 다음 봉 시가로 가상
  체결한 결과입니다. Studio와 백테스트 도구는 주문·정정·취소·환전 API 를 호출하지 않습니다.
- **과거 성과는 미래 수익을 보장하지 않습니다.** 백테스트 결과, 개선 후보, Walk-forward·기간 분리 검증은
  이미 본 과거 자료에 대한 사후 연구이며 투자권유나 수익 예측이 아닙니다.
- **기업행사를 반영하지 않습니다.** 배당 현금흐름, 액면분할·병합에 따른 보유 수량 조정, 환율 손익은
  계산에 들어가지 않습니다.
- **데이터 품질과 거래소 달력을 대조하지 않습니다.** 조회·가져온 시세의 누락·오류·휴장일 여부를 Studio 가
  검증하지 않으며, 봉 개수 기준의 기간은 달력 기간과 다릅니다. 품질 경고와 실제 받은 기간·봉 수를 확인하십시오.
- **수수료·세금·슬리피지는 사용자 가정입니다.** 기본값(거래세 0 포함)은 고객의 실제 요율이 아니며,
  설정한 값만 계산에 적용됩니다.
- **로컬 평문 저장입니다.** 전략·시세·결과는 고객 PC 의 SQLite 파일(macOS
  `~/Library/Application Support/Meritz Strategy Platform/`, Windows `%LOCALAPPDATA%\MeritzStrategy\`,
  Linux `~/.local/share/meritz-strategy/`)에 암호화 없이 저장되며 OS 파일 권한으로만 보호됩니다.
  지우려면 앱의 **로컬 데이터 초기화**를 사용하거나, 앱을 종료한 뒤 해당 폴더를 삭제하십시오. 시세 조회에
  입력한 App Key·Secret 은 디스크에 저장되지 않고 앱 실행 중 메모리에만 있습니다.
- **Studio 는 외부 AI 서비스로 데이터를 보내지 않습니다.** 고객용 Studio 에는 AI 연결·AI 생성 기능이
  없습니다. 아래 "연결한 AI 서비스로 정보가 전송됩니다" 절은 고객이 직접 `--mcp` 로 AI 호스트에 연결한
  **MCP 경로에만** 해당합니다. MCP 경로에서는 백테스트 도구의 결과(전략·성과·거래 요약)도 연결한 AI
  서비스로 전송됩니다.
- Python 전략은 macOS 격리 경로 또는 Windows 동봉 실행기에서만 실행하며, 격리를 사용할 수 없으면 실행을 거부합니다.

## 투자권유가 아닙니다

API 호출을 돕는 개발 보조 수단입니다.

- 투자자문·투자권유·매매 추천을 제공하지 않습니다.
- 조회되는 시세·잔고·수익률은 참고 정보이며, 투자 판단의 근거로 삼기 위한
  정확성과 완전성을 보장하지 않습니다.
- 투자 결정과 그 결과에 대한 책임은 전적으로 이용자에게 있습니다.

## 기본값은 운영 서버입니다

`MERITZ_BASE_URL` 을 지정하지 않으시면 운영 서버로 호출됩니다.
이 서버는 운영 호출을 막지 않습니다.

**기본이 조회 전용입니다.** 주문·환전을 쓰시려면 `MERITZ_READ_ONLY=0` 으로
두셔야 합니다. 그렇게 하시는 순간 실제 계좌에 주문이 나갈 수 있습니다.

## AI 에이전트가 주문을 냅니다

이 서버의 핵심 위험입니다.

- AI 는 사용자의 의도를 잘못 해석할 수 있습니다.
  **주문 파라미터(종목·수량·가격·매매구분)를 전송 전에 반드시 직접 확인해 주십시오.**
- 자동 반복 실행이나 무인 운영에 사용하지 말아 주십시오.
- 주문 실행으로 발생한 손실에 대해 책임지지 않습니다.

### 확인 절차가 보장하는 것과 보장하지 않는 것

주문과 환전은 두 단계입니다. 첫 호출은 전송하지 않고 보낼 내용과
`confirm_token` 만 돌려드립니다. 토큰은 한 번만 쓸 수 있고 180초 뒤 만료되며,
요청 값이나 대상 서버가 바뀌면 무효가 됩니다.

**이 절차는 `ApiClient.call()` 에 있습니다.** 이 서버가 노출하는 도구로 호출하시든,
같은 패키지의 파이썬 클라이언트를 코드에서 직접 호출하시든 똑같이 걸리며 끌 수 없습니다.
조회 전용 기본값도 두 경로 모두에 적용됩니다.

토큰 발급(`/oauth2/token`)만 이 게이트에서 제외돼 있습니다.
토큰 폐기(`/oauth2/revoke`)는 진행 중인 세션을 전부 끊으므로 주문처럼 미리보기와 확인 뒤에만 나갑니다.

**이 장치는 실수를 막기 위한 것이지, 사람이 내용을 확인했다는 증거는 아닙니다.**
에이전트가 미리보기를 받아 그 자리에서 `confirm_token` 을 넣어 다시 호출하는
것까지는 막지 못합니다.

무인 환경에서는 `MERITZ_READ_ONLY` 를 열지 마시고, 주문은 사람이 직접 하는
경로로 분리해 주십시오.

## 계좌 연결 주의

**앱키에는 계좌가 묶여 있습니다.** 계좌번호를 입력하지 않으셔도 해당 계좌의
잔고와 자산이 조회되고, 주문도 그 계좌로 전송됩니다.

앱키에 연결된 계좌는 실계좌입니다. 모의계좌라는 전제로 사용하지 말아 주십시오.

## 접수와 체결은 다릅니다

주문 응답이 성공(`rsp_cd`=`0001`)으로 오더라도 접수되지 않았을 수 있습니다.
`data.warn_cls_code` 가 경고 값이면 `warn_cnfr_yn` 을 채워(값은 해당 API 명세와 정정 안내를 따릅니다) 재전송하셔야 접수됩니다.
접수는 체결이 아닙니다. 최종 상태는 주문내역 조회로 확인해 주십시오.

## 이 서버에는 자체 인증이 없습니다

Streamable HTTP 로 띄우실 경우 로컬 포트를 인터넷에 직접 공개하지 마십시오.
연결할 수 있는 사람은 곧 주문할 수 있는 사람입니다.

터널로 임시 주소를 여실 경우, 주소의 난수 경로가 사실상 유일한 접근 통제이며
그 주소는 연결하신 AI 서비스 쪽에 커넥터 설정으로 저장됩니다. 이 구성에서는
`MERITZ_READ_ONLY=1`(조회 전용)로 두십시오. 주문까지 여시려면 사용자별 인증과
접근제어가 적용된 프록시 뒤에 두시고, 쓰신 뒤에는 터널을 닫아 주십시오.

대화 기록이 남는 환경에서는 그 기록에 계좌 정보가 축적된다는 점도 함께
고려해 주십시오.

## 자격증명과 민감정보

- 앱키(App Key)와 시크릿(App Secret)의 보관 책임은 이용자에게 있습니다.
  코드·저장소·로그·대화 기록에 남기지 마십시오. 환경변수로만 다뤄 주십시오.
- 접근토큰은 디스크에 저장되지 않고 프로세스 메모리에만 존재합니다.
- 계좌 조회 결과에는 잔고·총자산·보유종목 등 민감정보가 포함됩니다.
  화면 공유나 기록이 남는 환경에서 사용하실 때 주의해 주십시오.

## 연결한 AI 서비스로 정보가 전송됩니다

이 서버가 조회한 정보는 **이용자가 연결한 AI 서비스의 서버로 전송됩니다.**
어떤 AI 서비스에 연결할지는 이용자가 정하십니다.

- 전송된 정보의 저장·이용·보관 기간은 **해당 AI 서비스 사업자의 정책**에
  따릅니다. 대화 내용이 일정 기간 보관되거나 서비스 개선에 이용될 수
  있습니다.
- 메리츠증권은 AI 서비스 사업자의 데이터 처리에 관여하지 않으며, 해당
  사업자와 이를 위한 계약을 맺고 있지 않습니다.
- 연결하시려는 AI 서비스의 데이터 처리 정책과 보관 기간을 확인하신 후
  이용해 주십시오.

이 항목은 이 서버(도구) 자체의 동작에 대한 메리츠증권의 책임을 제한하지
않습니다.

## 단말 식별정보 전송

게이트웨이 요구에 따라 모든 요청 헤더에 실행 단말의 MAC 주소를 넣어 전송합니다
(`mac_address` 헤더, 없으면 `IGW50024` 로 거절됩니다).
수집·이용에 관한 사항은 메리츠증권 Open API 이용약관 및 개인정보 처리방침에 따릅니다.

## 명세의 한계

- 카탈로그와 명세 파일은 개발자 포털의 공개 API 정보를 기준으로 생성됩니다. 실제 이용 시에는 개발자 포털의 최신 명세와 API별 권한을 확인하십시오.
- 응답 처리 참고자료는 알려진 API별 처리 방법을 설명하며, 모든 운영 환경과 응답 변형을 포괄하지는 않습니다.
- 응답 코드가 손상되어 오는 API 가 있습니다. 그런 응답은 데이터를 돌려드리되
  "검증되지 않음" 으로 표시합니다.

## 보증의 부인과 책임의 한계

이 저장소는 **있는 그대로(as-is)** 제공되며, 특정 목적 적합성·정확성·중단 없는
동작을 보증하지 않습니다.

관련 법령이 허용하는 범위에서, 메리츠증권은 이 코드의 이용 또는 이용 불능으로
발생한 손해에 대해 책임을 지지 않습니다. 다만 메리츠증권의 고의 또는 중대한
과실로 인한 손해, 그 밖에 법령상 배제할 수 없는 책임은 그러하지 아니합니다.

이 조항은 메리츠증권 Open API 이용약관 및 이용자와 메리츠증권 사이의 거래관계에
따라 발생하는 책임을 제한하거나 변경하지 않습니다.
